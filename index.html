Hong Kong Octopus Gate System

Tap the reader to start a trip and see how an information system works.

Purpose

Enable fast, automated, cashless fare collection to reduce queues and improve efficiency.

Manual Cash Payment

  • Queue to buy/prepare exact fare
  • Slower passenger flow at gates
  • More manual handling by staff

Automated Octopus System

  • Quick tap-and-go experience
  • Fast passenger movement
  • Automatic fare deduction and records

Technology

Simple equipment and software work together at every gate.

📶 Card Reader

Reads the card when passengers tap.

🖥️ Gate Screen & Speaker

Displays balance and plays the "Doo" chime.

🚧 Gate Barriers

Open for valid payment and control access flow.

⚙️ Fare Software

Calculates fare and updates transaction records.
